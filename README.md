# 📦 AstrBot 本地文件备份储存插件 v2.2

一个强大的本地文件备份管理插件，支持手动备份、定时备份、多路径监控和待转发队列机制。

## ✨ 功能特性

- 💾 **手动备份** - 将本地文件保存到备份目录
- ⏰ **定时备份** - 按设定间隔自动备份监控目录中的新文件
- 📁 **多路径监控** - 支持配置多个监控路径，自动扫描备份
- 🚀 **待转发队列** - 备份完成后自动加入队列，用户手动执行转发
- 📜 **备份历史** - 记录所有备份操作，方便追溯
- 🔢 **序号操作** - 通过序号快速操作文件，方便快捷
- 🔄 **自动清理** - 自动清理过期备份文件
- 🛡️ **权限控制** - 可限制只有指定用户能使用

## 📁 支持的文件类型

| 类型     | 格式                             | 转发方式   |
| ------ | ------------------------------ | ------ |
| 🖼️ 图片 | png, jpg, jpeg, webp, gif, bmp | 直接发送图片 |
| 🎬 视频  | mp4, avi, mov, mkv             | 作为视频发送 |
| 🔊 音频  | mp3, wav, ogg, aac, flac       | 作为语音发送 |
| 📄 文档  | pdf, doc, docx, txt 等          | 作为文件发送 |

## 🚀 快速开始

### 1. 安装插件

将 `backup_storage` 文件夹复制到AstrBot的插件目录：

```
AstrBot插件目录/backup_storage/
├── main.py              # 主代码文件
├── metadata.yaml        # 插件元数据
├── _conf_schema.json    # 配置架构
└── README.md             # 使用说明
```

### 2. 配置插件

在AstrBot管理界面中配置以下参数：

#### 基础配置

| 配置项                   | 说明            | 默认值              |
| --------------------- | ------------- | ---------------- |
| `backup_dir`          | 备份文件存储目录      | ./backup-storage |
| `max_file_size_mb`    | 单个文件最大大小（MB）  | 100              |
| `auto_cleanup_days`   | 自动清理天数（0=不清理） | 30               |
| `allowed_users`       | 允许使用的用户ID列表   | 全部用户             |
| `keep_backup_history` | 保留备份历史天数      | 7                |

#### 定时备份配置

| 配置项                             | 说明         | 默认值   |
| ------------------------------- | ---------- | ----- |
| `enable_timed_backup`           | 启用定时备份     | false |
| `timed_backup_interval_minutes` | 定时备份间隔（分钟） | 30    |
| `monitor_paths`                 | 监控路径列表     | \[]   |
| `monitor_file_types`            | 监控文件类型     | \[]   |

#### 自动转发配置

| 配置项                          | 说明        | 默认值   |
| ---------------------------- | --------- | ----- |
| `enable_auto_forward`        | 启用自动转发    | false |
| `auto_forward_delay_seconds` | 自动转发延迟（秒） | 10    |

## 🚀 核心功能：待转发队列

### 工作原理

```
定时备份扫描监控路径
    ↓
发现新文件，备份到存储目录
    ↓
备份完成后延迟（可配置）
    ↓
自动加入待转发队列
    ↓
用户输入 /执行转发
    ↓
文件依次发送到当前群聊
```

### 为什么使用队列模式？

1. **避免发送失败**：直接发送可能因平台限制失败
2. **用户可控**：用户可以决定何时发送
3. **批量处理**：可以一次性发送多个文件
4. **灵活取消**：用户可以在执行前查看队列并决定是否发送

## 💡 完整使用场景

### 场景1：自动备份下载目录

**配置：**

```json
{
    "enable_timed_backup": true,
    "timed_backup_interval_minutes": 10,
    "monitor_paths": ["C:/Users/Admin/Downloads"],
    "monitor_file_types": ["mp4", "jpg", "png"],
    "enable_auto_forward": true,
    "auto_forward_delay_seconds": 10
}
```

**效果：**

1. 每10分钟自动扫描下载目录
2. 发现新的 mp4、jpg、png 文件
3. 自动备份到存储目录
4. 备份完成后延迟10秒
5. 文件加入待转发队列
6. 用户输入 `/执行转发` 发送文件到群聊

### 场景2：监控多个目录

**配置：**

```json
{
    "enable_timed_backup": true,
    "timed_backup_interval_minutes": 30,
    "monitor_paths": [
        "C:/Users/Admin/Documents",
        "D:/Work/Projects",
        "E:/Archive"
    ],
    "monitor_file_types": ["pdf", "docx", "xlsx"],
    "enable_auto_forward": false
}
```

**效果：**

- 每30分钟自动扫描三个目录
- 只备份 pdf、docx、xlsx 格式的新文件
- 备份文件不会自动加入转发队列
- 用户需要手动使用 `/转发备份 [序号]` 发送

📝 注意事项

1. **序号时效性**：序号基于当前文件列表，删除文件后序号会重新排列
2. **文件路径**：支持绝对路径和相对路径
3. **文件大小**：默认最大100MB，超过会被拒绝
4. **自动清理**：默认30天自动清理，可设置为0禁用
5. **定时间隔**：最小支持5分钟一次
6. **哈希去重**：通过文件哈希判断是否已备份，避免重复备份
7. **转发队列**：队列中的文件会一直保留，直到用户执行 `/执行转发`

## 🔧 故障排除

### Q: 定时备份没有执行？

A: 检查：

- 是否设置了 `enable_timed_backup = true`
- 是否配置了 `monitor_paths`
- 查看 AstrBot 日志中的 `[backup_storage]` 信息

### Q: 文件没有被自动备份？

A: 检查：

- 文件是否在监控路径中
- 文件类型是否在 `monitor_file_types` 中（如果配置了）
- 文件大小是否超过限制

### Q: 提示"无效序号"？

A: 检查：

- 序号是否在有效范围内（1 \~ 文件总数）
- 是否使用了阿拉伯数字（不是中文数字）
- 先使用 `/查看备份` 查看当前文件列表

### Q: 待转发队列为空？

A: 检查：

- 是否设置了 `enable_auto_forward = true`
- 查看 `/备份状态` 确认自动转发是否启用
